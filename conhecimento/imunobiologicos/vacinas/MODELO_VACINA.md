# 💉 Modelo de Vacina

## Objetivo

Este documento define a estrutura padrão utilizada para documentar todos os imunobiológicos classificados como vacinas na Trilha de Imunização.

Toda vacina deverá seguir este modelo, garantindo padronização, comparabilidade, rastreabilidade e integração com os demais Objetos de Conhecimento.
