# 💉 Imunobiológicos

## Objetivo

Esta seção reúne todos os imunobiológicos utilizados pelo Programa Nacional de Imunizações (PNI), organizando o conhecimento técnico, os documentos oficiais, os sistemas relacionados e as principais dúvidas encontradas na prática dos serviços de imunização.

Cada imunobiológico possui uma Unidade de Conhecimento própria, construída a partir de documentos oficiais e organizada de forma padronizada para facilitar consultas, aprendizado e futuras integrações com a Inteligência Artificial da Trilha.

---

## Estrutura

Cada imunobiológico será documentado seguindo o mesmo padrão:

- O que é
- Composição
- Indicações
- Esquema vacinal
- Situações especiais
- Contraindicações
- Eventos adversos
- Conservação
- Registro nos sistemas oficiais
- Documentos oficiais relacionados
- Perguntas frequentes
- Casos práticos

## Princípio

Cada imunobiológico representa uma Unidade de Conhecimento da Trilha de Imunização.

A Inteligência Artificial utilizará essas Unidades de Conhecimento para construir respostas fundamentadas em documentos oficiais, considerando o contexto apresentado pelo usuário.
