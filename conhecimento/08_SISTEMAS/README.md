# 💻 Sistemas de Informação

## Objetivo

Esta seção reúne os sistemas oficiais utilizados no ecossistema da imunização brasileira.

Mais do que apresentar cada sistema individualmente, a Trilha busca explicar sua finalidade, seu papel no fluxo de trabalho e como ele se relaciona com os demais componentes do Programa Nacional de Imunizações.

---

## O que o profissional encontrará aqui?

Cada sistema será apresentado de forma padronizada, respondendo perguntas como:

- O que é este sistema?
- Qual é sua finalidade?
- Quem utiliza?
- Em quais situações ele é utilizado?
- Como se relaciona com outros sistemas?
- Quais documentos oficiais o regulamentam?
- Quais são as dúvidas mais frequentes?

## Princípio

Os sistemas de informação não devem ser estudados isoladamente.

A Trilha apresentará cada sistema dentro do contexto do ecossistema da imunização, permitindo compreender como os dados circulam entre a assistência, a vigilância, a gestão e os serviços de saúde.
