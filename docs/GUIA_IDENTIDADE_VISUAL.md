# 🎨 Guia de Identidade Visual — Trilha de Imunização

## Objetivo

Este documento define a identidade visual oficial da Trilha de Imunização.

Seu objetivo é garantir que todas as páginas, módulos e futuras funcionalidades mantenham o mesmo padrão visual, proporcionando uma experiência agradável, intuitiva e profissional.

---

# Nossa filosofia de design

A interface deve transmitir:

* Confiança
* Organização
* Clareza
* Rapidez
* Simplicidade
* Acolhimento

O usuário nunca deve sentir que está diante de um sistema complicado.

Nosso objetivo é reduzir o tempo gasto procurando informações.

---

# Lema da Plataforma

> **Menos tempo procurando. Mais tempo cuidando das pessoas.**

Todo elemento visual deverá reforçar esse propósito.

# Estilo das páginas

Todas as páginas deverão possuir:

* muito espaço em branco;
* poucos elementos por tela;
* navegação intuitiva;
* leitura rápida;
* design responsivo;
* carregamento leve.

---

# Página Inicial

A Home deverá conter:

* logotipo;
* nome da plataforma;
* slogan;
* barra de pesquisa;
* acesso aos módulos;
* informações institucionais.

---

# Princípios de UX

O profissional deve conseguir encontrar uma informação importante em poucos segundos.

Sempre que houver dúvida entre adicionar mais elementos ou simplificar a tela, a simplicidade deverá prevalecer.

---

# Nosso compromisso

A identidade visual não existe apenas para deixar a plataforma bonita.

Ela existe para tornar o trabalho dos profissionais mais fácil, mais rápido e mais seguro.
